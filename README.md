This repo holds small, focused STM32 exercises — one folder per peripheral or concept, built while learning and testing before moving into full projects. For complete builds, see [STM32-Projects](YOUR_PROJECTS_REPO_LINK).

Each folder contains the source code for that test. Full project history (including earlier iterations) is on the Drive link above.

## What's inside

| Category | Examples |
|---|---|
| **UART** | Polling, interrupt, DMA RX, multi-board UART |
| **SPI** | Polling, interrupt (master/slave), DMA (master/slave) |
| **I2C** | EEPROM read/write, LCD over I2C |
| **ADC** | DMA (single/multi-channel), timer-triggered, interrupt-based |
| **Timers** | PWM generation, counter mode |
| **CAN** | Basic CAN communication |
| **LCD** | Character LCD interfacing |
| **Interrupts & Tasks** | Round-robin scheduling, keypad/button handling |
